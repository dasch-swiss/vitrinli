## Closeout

- root_cause: Advisory coverage followed the build artefact, not the build graph. Docker Scout scanned the distroless image, whose one statically linked binary carries no package metadata, so the C/C++ libraries and every crate were invisible to it; the only other feed was a Rust-only `dependency-audit` that failed every PR on any matched advisory, and Debian, base-image and Actions pins drifted unwatched.
- investigation: The spike over a fixture with one vulnerable component per class settled the scanner split empirically: Grype alone matched every fixture class but missed RustSec-only advisories on the real tree (RUSTSEC-2026-0387, RUSTSEC-2023-0071), while OSV-Scanner matched a deb only under its source name; deb purls needed `upstream=<source>` and Actions components `syft:package:type=github-action` before Grype matched them. The baseline came out at 268 findings (265 open), far beyond the four carried-over ignores. macOS 27 coverage segfaulted at exit before any change, so CI's linux coverage leg stayed the gate. The final cross-phase review found the fix job handing DASCHBOT_PAT to any dispatched branch and the rolling issue re-deriving declined-PR state with a weaker rule than fix.py; both were fixed.
- solution: A stdlib Python toolset under tools/advisories derives a CycloneDX inventory from the Bazel inputs (Cargo.Bazel.lock, MODULE.bazel.lock source.json keys, http_archive URLs, the Debian lock, the oci.pull digest, workflow `uses:`), with a drift-checked component map holding no versions; scan.py runs OSV-Scanner for crates and Grype for the rest under one expiring ignore file; diff.py gates PRs and releases on head-minus-base keyed by (component, advisory); a daily workflow keeps one rolling issue with a pin table and opens fix PRs for crates, BCR modules, the base digest and the Debian snapshot. Docker Scout, `dependency-audit`, `just audit`, cargo-audit and osv-scanner.toml are gone, and the image lost Debian curl (33 to 4 packages per arch). ADR-0029 records the reversals.
- prevention: Offline unittest suite (209 tests) over recorded scanner and ls-remote output, run in the PR job; the drift check fails CI on an unclassified dependency; scanner errors always exit 3 and never read as clean; expiring ignores return findings to a person; the release gate runs before any push. Avoid: keying diffs by version, trusting a scanner's own ignore config, a PATH change in Bazel steps, and folding cross-phase fixups mid-run on a pushed branch.
